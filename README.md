Rock Paper Scissors Game 🎮

About the Project

This is a simple Rock Paper Scissors game developed using Python. The user plays against the computer by choosing Rock, Paper, or Scissors. The program determines the winner based on the rules of the game.

Features

- Play against the computer.
- Random computer choices.
- Automatically determines the winner.
- Simple and easy-to-use interface.

Rules of the Game

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both choices are the same, it is a draw.

Technologies Used

- Python
- Random module

How to Run

1. Download or clone this repository.
2. Open the project in Visual Studio Code.
3. Run the Python file.
4. Enter your choice and enjoy the game!
